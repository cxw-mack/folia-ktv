# 家庭 KTV 使用说明

本改造基于 Folia 桌面版增加当前歌曲的原唱 / 伴奏切换，以及手机扫码搜索点歌。电脑是唯一的音频播放端；手机网页只负责搜索歌曲、查看播放状态和向桌面队列点歌。

## 启动开发版

要求 Node.js 24 或更新版本。在项目根目录运行：

```powershell
npm ci
npm run models:fetch
npm run dev:electron
```

启动器会检查 Node.js 和 Electron 依赖；启动输出写入 `logs/ktv-launch.log`，启动异常时可查看该文件。CPU 分离运行库按打包配置加载；开发环境需按桌面开发说明准备 MNN / FFmpeg 运行时，也可通过 `FOLIA_MNN_LIBRARY` 指定 MNN DLL。

`models:fetch` 会按 `shared/modelManifest.json` 校验并下载人声分离模型；HTDemucs 权重约 92 MB。构建桌面安装包时，打包流程也会自动准备已校验的模型，并把它们放入安装包。模型文件保存在忽略跟踪的 `models/` 目录，不需要提交到 Git。

开发模式下如果缺少 Electron 二进制或 MNN / FFmpeg 运行时，请按仓库的桌面开发说明完成相应初始化。`npm run dev:electron` 会启动 Vite 和 Electron 桌面窗口。

## 原唱和伴奏

1. 在 Folia 中开始播放歌曲，点击窗口右上角的 **KTV**，或打开 KTV 控制台。
2. 选择 **伴奏**，或打开“自动生成当前歌曲伴奏”。播放会继续；桌面会读取可用的本机音源，并调用 Folia 内置的 HTDemucs 分轨模型，按播放位置优先逐段生成伴奏。处理器自动优先选 WebGPU；GPU 不可用或某段 GPU 推理失败时，自动切到 CPU（MNN），并让当前歌曲后续片段继续使用 CPU。
3. 已经生成的时间段可在原唱和伴奏间快速切换。某段还没准备好、播放位置刚跳到未覆盖区间，或当前音频正在缓冲时，会暂时听到原唱；面板会显示处理状态、完成比例和当前位置前的伴奏缓冲长度。

原唱与伴奏使用同一首歌的播放时钟，切换不会重新开始歌曲。为了维持歌词与两路音频同步，启用 KTV 伴奏时会暂停 Automix；变速播放目前继续播放原唱，避免伴奏变调。KTV 开关和生成音频仅保存在当前运行会话中。

## 手机扫码点歌

1. 在 KTV 控制台点击 **开启扫码点歌**，用手机相机扫描桌面显示的二维码。
2. 手机和桌面主机需要位于互相可访问的同一局域网。手机页面显示当前播放歌曲和队列，可切换当前在线平台或本地曲库、搜索并点歌。
3. 点歌经 Folia 队列操作加入。当前没有播放歌曲时，第一首点歌会在桌面端自动开始播放；有正在播放的歌曲时不会打断它。
4. 房主可复制链接、刷新二维码或关闭点歌房。房间最长开启 6 小时；刷新二维码会撤销旧链接和已经加入的手机会话。

手机不获得播放音频、文件路径或 Folia Stage API 令牌。房间使用临时加入凭据，限制请求频率和人数；访客只能搜索和点歌。在线搜索走 Folia 当前选择的平台，手机选择本地曲库时只检索桌面已导入的歌曲。

如果二维码提示“本机访问”，桌面找不到可用的局域网 IPv4 地址。若手机打不开链接，请检查 Windows 防火墙是否允许 Folia 在“专用网络”通信、路由器是否开启设备隔离，以及两台设备是否真的处于同一个可互访的 Wi-Fi / 局域网。不要把房间链接转发到公网；结束使用后关闭点歌房。

## 性能和当前限制

- 人声分离按当前歌曲后台逐段进行；切到尚未生成的区间会先保留原唱，直到伴奏可用。不会承诺每台电脑都能在播放头之前完成处理。
- WebGPU 可用时优先使用 GPU；GPU 不可用或推理失败时自动回退到桌面 CPU/MNN。CPU 处理可能慢于实时播放，所以伴奏按播放位置逐段生成，尚未就绪的片段继续播放原唱。实际速度和渲染影响会受 CPU、显卡、驱动、GPU 上其他任务、网络音源和歌曲编码影响。
- 输入歌曲最长 10 分钟，读取完整曲目前的网络音频最多 96 MiB。在线平台如果只提供试听片段、受限流、无法读取的音源或无可用完整缓存，伴奏会显示无法准备；本功能不会绕过平台访问限制。
- 当前只生成正在播放歌曲的伴奏；任务结束后不持久化生成的 PCM，也不会预处理队列里的歌曲。
- 该控制台和局域网点歌房需要 Electron 桌面版。Web 版没有桌面 LAN IPC 服务。

## 测试建议

提交代码前可运行 `npm run typecheck`、`npm run test:unit` 和 `npm run build`。人声分离速度和手机点歌连接会受设备、驱动、音源、Windows 防火墙及路由器设置影响，应在目标电脑和手机上实测。
