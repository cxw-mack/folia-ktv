Folia KTV Windows x64 绿色版

使用方法
1. 将整个压缩包解压到可写的文件夹。
2. 双击 Folia-KTV.exe。无需安装 Node.js、Python 或另行下载伴奏模型。
3. 第一次使用在线音乐时，在应用内登录你自己的音乐平台账号。

不要只复制 EXE；resources、locales、DLL 和其他配套文件需要保持在一起。
以后换电脑，请复制整个 Folia-KTV 文件夹。设置和缓存保存在同目录 data 文件夹，
应用运行日志可在 logs 中查看。账号的加密凭据可能需要在新电脑重新登录。
本包没有预置制作电脑的账号、歌库或私人配置。更新请使用后续提供的完整绿色包；
这个 KTV 版本不会自动安装上游原版更新。

伴奏功能
开始播放歌曲，打开 KTV 控制台，选择原唱或伴奏。
已内置 HTDemucs / Beat This 模型、MNN CPU 运行库及音频解码程序。
有可用的 WebGPU 时优先 GPU；不可用或处理失败时自动退回 CPU。
生成速度受歌曲长度、处理器和显卡影响；尚未准备好的片段会先播放原唱。
本地歌曲及伴奏处理无需额外部署服务器；在线搜索、登录及在线歌曲需要联网。

手机扫码点歌
在 KTV 控制台开启扫码点歌。首次开启时 Windows 会请求允许添加局域网防火墙规则，请选择“是”；该规则仅允许本应用接收来自本地子网的 TCP 连接。手机连接与电脑可互访的同一局域网后扫描二维码。
若扫码页面打不开，请点击“手机打不开？修复局域网连接”，并检查二维码旁显示的完整地址（包括端口）；也可复制完整链接后粘贴到手机浏览器。iPhone 用户还需在“设置 > 微信 > 本地网络”允许访问。
路由器访客网络或 AP 隔离会阻止手机访问电脑。更换电脑或网络后应重新开启点歌房。
手机页面可控制上一首、下一首、播放/暂停，切换原唱或伴奏，并开启/关闭当前歌曲伴奏生成。
页面同步显示生成状态、进度和可用伴奏缓冲；生成失败时可在手机上重试。

兼容范围
Windows 10 / 11 64 位（x64）。不支持 Windows 7 / 8 或 32 位 Windows。
这是目录式绿色版，每次启动不会进行单文件安装包的临时解压。
